##### Abstract

Official publication is coming Soon ...

A preprint is available [here](http://arxiv.org/abs/2606.08313). 

Check out this [GitHub Repository](https://github.com/kunmok/FFNE-stat-and-time-domain-simulator) for statistical- and time-domain analysis. 
I have released a public GitHub repository accompanying my upcoming arXiv preprint on Feedforward Nonlinear Equalizers (FFNE) for high-speed wireline communication.

The repository includes statistical BER models (for both DFE and FFNE), time-domain simulation scripts, and plotting utilities for evaluating receive-side FFNE architectures, including Pattern-Detector FFNE (PD-FFNE), Win-2 FFNE, and Win-3 FFMLSE-style equalizers. It also provides comparison scripts against conventional DFE baselines for NRZ and PAM-4 channels modeled from Touchstone .s4p files.

The codebase contains both MATLAB reference implementations and Python simulation/plotting ports. The MATLAB sources serve as the mathematical reference for the analytical models and decision-region visualizations, while the Python scripts provide convenient time-domain simulation workflows and reproduction paths for manuscript figures.
